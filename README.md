## FEATURES
A highly customisable WhatsApp multi-device bot with:
- Group management (admin tools, welcome/goodbye, anti-link, anti-call, etc.)
- Media commands (stickers, image effects, YouTube/TikTok/Twitter downloads)
- AI chat (OpenAI GPT, Google Gemini)
- And much more

## SET-UP

### 1. Get a Session
Generate your WhatsApp session string using the pairing tool:

[![Session](https://img.shields.io/badge/Get%20Session-green?style=for-the-badge&logo=render)](https://perez-md-pairing.onrender.com)

### 2. Required Environment Variables

| Variable | Description |
|---|---|
| `SESSION` | Base64 WhatsApp session from pairing tool |
| `BOTNAME` | Bot display name (default: `⚡ 𝔸𝕤𝕥𝕒𝕩ℕ𝕖𝕩𝕦𝕤 𝕄𝔻`) |
| `PORT` | HTTP port (default: `8000`) |
| `DATABASE_URL` | PostgreSQL connection string |
| `STICKER_PACKNAME` | Sticker pack label |
| `STICKER_AUTHOR` | Sticker author label |
| `DEV` | Owner phone number (e.g. `254700000000`) |

### 3. Run

```bash
npm install
node index.js
```
